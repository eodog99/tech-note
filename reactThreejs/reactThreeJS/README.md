# ⚛️ React + Three.js (R3F) Interactive Dashboard R&D

이 프로젝트는 **React** 환경에서 **Three.js(React Three Fiber)**를 활용하여 고성능 3D 인터페이스를 구축하기 위한 연구용 레포지토리입니다.  
컴포넌트 기반 설계를 통해 3D 요소의 재사용성을 높이고, 상태 관리 라이브러리와의 연동을 목표로 합니다.

---

## 🛠 Tech Stack

*   **Framework:** React.js
*   **3D Engine:** Three.js / React Three Fiber (R3F)
*   **Helper:** React Three Drei
*   **State Management:** React Hooks (useState, useEffect, useRef)

---

## 🚀 Key Learning Points

*   **Declarative 3D:** Three.js의 명령형 코드를 React의 선언적 컴포넌트로 구조화하는 방식 습득
*   **Hooks Integration:** `useFrame`, `useThree` 등 R3F 전용 훅을 활용한 실시간 애니메이션 및 카메라 제어
*   **Performance:** React 렌더링과 별개로 작동하는 3D 캔버스의 최적화 기법 연구
*   **Event Handling:** React Props 방식을 활용한 3D 오브젝트의 클릭 및 호버 이벤트 처리

---

## 📂 주요 구현 내용

1. **R3F 환경 설정:** React 프로젝트 내 3D 캔버스 최적화 배치
2. **Interactive Components:** 상태 변화에 따라 실시간으로 반응하는 3D 매쉬(Mesh) 구현
3. **Data Mapping:** 외부 데이터(JSON 등)를 기반으로 3D 공간 내 오브젝트를 동적으로 생성하는 로직 연구
