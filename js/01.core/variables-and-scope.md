# Variable & Scope

자바스크립트에서 변수의 개념과 생명 주기, 그리고 스코프에 대해 정리한다.

---

# 1. 변수 (Variable)

## 변수란 무엇인가?

변수는 **하나의 값을 저장하기 위해 확보한 메모리 공간 자체** 또는  
**그 메모리 공간을 식별하기 위해 붙인 이름**을 말한다.

즉, 변수는 값을 저장하고 참조하기 위한 **식별자 역할**을 한다.

```javascript
var age = 20;
```

---

## 여러 개의 값을 저장하는 방법

변수는 **기본적으로 하나의 값만 저장**할 수 있다.

하지만 배열이나 객체 같은 **자료구조**를 사용하면 여러 값을 하나의 값처럼 사용할 수 있다.

```javascript
// 변수는 하나의 값을 저장한다
var userId = 1;
var userName = 'Lee';

// 객체를 사용하면 여러 값을 하나로 묶을 수 있다
var user = {
  id: 1,
  name: 'Lee'
};

// 배열을 사용하면 여러 데이터를 관리할 수 있다
var users = [
  { id: 1, name: 'Lee' },
  { id: 2, name: 'Kim' }
];
```

---

# 2. 식별자 (Identifier)

식별자는 **어떤 값을 구별해서 식별할 수 있는 고유한 이름**이다.

사람을 이름으로 구별하는 것처럼  
자바스크립트에서는 **식별자를 통해 값을 구별**한다.

식별자는 **값 자체를 저장하는 것이 아니라 메모리 주소를 기억**하고 있다.

---

# 3. 변수 선언

변수를 사용하려면 **반드시 선언해야 한다.**

자바스크립트에서는 다음 키워드를 사용해 변수를 선언한다.

- `var`
- `let`
- `const`

```javascript
var score;
```

만약 선언하지 않은 식별자에 접근하면 다음과 같은 오류가 발생한다.

```
ReferenceError
```

---

# 4. 변수 선언과 호이스팅

자바스크립트에서는 **변수 선언이 코드 실행 이전에 먼저 처리된다.**

예시:

```javascript
console.log(score); // undefined

var score;
```

이 코드가 에러 없이 실행되는 이유는  
**변수 선언이 런타임 이전에 먼저 실행되기 때문**이다.

이처럼 **변수 선언이 코드의 최상단으로 끌어올려진 것처럼 동작하는 현상**을  
**호이스팅(Hoisting)** 이라고 한다.

---

# 5. 값의 할당

변수에 값을 저장할 때는 **할당 연산자(`=`)** 를 사용한다.

```javascript
var score;
score = 80;
```

또는 선언과 동시에 값을 할당할 수도 있다.

```javascript
var score = 80;
```

여기서 중요한 점은 다음과 같다.

- **변수 선언 → 런타임 이전**
- **값의 할당 → 런타임에 실행**

---

# 6. 값의 재할당

이미 값을 가진 변수에 **새로운 값을 다시 할당하는 것**을 재할당이라고 한다.

```javascript
var score = 80;
score = 90;
```

재할당이 불가능한 변수는 **상수(constant)** 라고 한다.

```javascript
const score = 80;
```

`const`로 선언한 변수는 **한 번만 값을 할당할 수 있다.**

---

## 메모리 관점에서의 재할당

값을 재할당할 때 기존 값을 덮어쓰는 것이 아니라  
**새로운 메모리 공간을 확보하고 새로운 값을 저장한다.**

기존 값은 더 이상 참조되지 않으면  
**가비지 컬렉터(Garbage Collector)** 에 의해 제거된다.

---

## 가비지 컬렉터

가비지 컬렉터는 **더 이상 사용되지 않는 메모리를 자동으로 해제하는 기능**이다.

자바스크립트는 가비지 컬렉터를 내장한 **매니지드 언어**이기 때문에  
개발자가 직접 메모리를 관리하지 않아도 된다.

---

# 7. 식별자 네이밍 규칙

식별자는 다음 규칙을 따라야 한다.

- 문자
- 숫자
- 언더스코어 `_`
- 달러 기호 `$`

단 다음 규칙을 지켜야 한다.

- 숫자로 시작할 수 없다
- 예약어는 사용할 수 없다

예시:

```javascript
var userName;
var $element;
var _count;
```

---

# 8. 스코프 (Scope)

스코프는 **변수가 유효한 범위**를 의미한다.

즉, 변수를 **어디서 참조할 수 있는지 결정하는 규칙**이다.

---

## 전역 스코프

전역 스코프는 **코드 어디에서든 접근 가능한 범위**를 의미한다.

```javascript
var x = 1;

function test() {
  console.log(x);
}
```

---

## 지역 스코프

지역 스코프는 **특정 블록이나 함수 내부에서만 접근 가능한 범위**이다.

```javascript
function test() {
  var x = 10;
}

console.log(x); // 오류
```

---

# 9. 전역 변수의 문제점

전역 변수는 프로그램 어디에서든 접근할 수 있기 때문에  
다음과 같은 문제가 발생할 수 있다.

### 1. 변수 충돌 가능성
같은 이름의 변수가 생길 수 있다.

### 2. 코드 의존성 증가
여러 곳에서 사용되면 코드가 복잡해진다.

### 3. 프로그램 안정성 저하
예상치 못한 값 변경이 발생할 수 있다.

따라서 **전역 변수 사용은 최소화하는 것이 좋다.**

---

# 10. let / const 와 블록 스코프

`var`는 **함수 스코프(function scope)** 를 가진다.

반면 `let`과 `const`는 **블록 스코프(block scope)** 를 가진다.

```javascript
if (true) {
  let x = 10;
}

console.log(x); // ReferenceError
```

블록 스코프를 사용하면  
**변수의 유효 범위를 명확하게 제한할 수 있다.**

---

# 정리

- 변수는 값을 저장하기 위한 메모리 공간의 이름이다.
- 식별자는 메모리 주소를 통해 값을 참조한다.
- 변수 선언은 런타임 이전에 실행되며 이를 호이스팅이라고 한다.
- 스코프는 변수의 유효 범위를 결정한다.
- 전역 변수는 최소화하는 것이 좋다.
- `let`과 `const`는 블록 스코프를 가진다.

---

## 느낀 점

변수는 단순히 값을 저장하는 개념이라고 생각했지만  
메모리와 식별자 관점에서 이해해야 한다는 것을 알게 되었다.

특히 `var`의 호이스팅과 전역 변수의 문제점 때문에  
실무에서는 `let`과 `const` 사용이 권장된다는 점!
