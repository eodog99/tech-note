# Execution Context

실행 컨텍스트는 **자바스크립트의 동작 원리를 이해하기 위한 핵심 개념**이다.

실행 컨텍스트를 이해하면 다음 개념들을 함께 이해할 수 있다.

- 스코프
- 호이스팅
- 클로저
- this 바인딩
- 비동기 처리 (이벤트 루프)

즉 **자바스크립트 코드가 어떻게 실행되는지 관리하는 메커니즘**이다.

---

# 1. 소스코드의 타입

ECMAScript 사양은 소스코드를 4가지 타입으로 구분한다.

각 소스코드는 **자신만의 실행 컨텍스트를 생성한다.**

## 1. 전역 코드 (Global Code)

전역에 존재하는 소스코드이다.

포함되지 않는 것
- 함수 내부 코드
- 클래스 내부 코드

예

```javascript
var x = 1;

function foo() {}
```

---

## 2. 함수 코드 (Function Code)

함수 내부에 존재하는 소스코드이다.

```javascript
function foo() {
  var x = 10;
}
```

---

## 3. eval 코드

빌트인 함수 `eval()`에 의해 실행되는 코드이다.

```javascript
eval("var x = 10");
```

---

## 4. 모듈 코드 (Module Code)

ES6 모듈 내부 코드이다.

```javascript
import { foo } from "./foo.js";
```

모듈은 **독립적인 모듈 스코프를 가진다.**

---

# 2. 소스코드의 평가와 실행

자바스크립트 엔진은 소스코드를 **두 단계로 나누어 처리한다.**

```
1. 소스코드 평가
2. 소스코드 실행
```

---

## 1. 소스코드 평가 단계

이 단계에서 실행되는 것

- 실행 컨텍스트 생성
- 변수 선언
- 함수 선언

즉 **선언문만 먼저 실행된다.**

이때 생성된 식별자는 **실행 컨텍스트의 스코프에 등록된다.**

예

```javascript
var x;
function foo() {}
```

---

## 2. 소스코드 실행 단계

평가 단계가 끝나면 **런타임이 시작된다.**

이 단계에서 실행되는 것

- 변수 값 할당
- 함수 호출
- 일반 코드 실행

예

```javascript
x = 10;
foo();
```

---

# 3. 실행 컨텍스트란

실행 컨텍스트는

> **코드를 실행하는 데 필요한 환경을 제공하고 실행 결과를 관리하는 영역**

이다.

즉 다음 두 가지 역할을 한다.

1️⃣ 식별자 관리  
2️⃣ 코드 실행 순서 관리

실행 컨텍스트는 내부적으로 다음 구조로 관리된다.

```
식별자 관리 → 렉시컬 환경
실행 순서 관리 → 실행 컨텍스트 스택
```

---

# 4. 실행 컨텍스트 스택

실행 컨텍스트는 **스택(stack) 구조로 관리된다.**

이를 **실행 컨텍스트 스택**이라고 한다.

코드 실행 흐름

1. 전역 코드 실행
2. 함수 호출
3. 함수 실행
4. 함수 종료

---

## 실행 예시

```javascript
const x = 1;

function foo() {
  const y = 2;
  bar();
}

function bar() {
  const z = 3;
}

foo();
```

실행 흐름

```
1. 전역 실행 컨텍스트 생성
2. foo 실행 컨텍스트 생성
3. bar 실행 컨텍스트 생성
4. bar 종료
5. foo 종료
```

스택 구조

```
[bar 실행 컨텍스트]
[foo 실행 컨텍스트]
[전역 실행 컨텍스트]
```

가장 위에 있는 컨텍스트를 **실행 중인 컨텍스트**라고 한다.

---

# 5. 렉시컬 환경 (Lexical Environment)

렉시컬 환경은

> **식별자와 식별자에 바인딩된 값을 관리하는 환경**

이다.

렉시컬 환경은 두 가지 구성 요소로 이루어진다.

```
1. 환경 레코드
2. 외부 렉시컬 환경 참조
```

---

## 1. 환경 레코드

현재 스코프에 선언된 식별자를 저장한다.

예

```
var x
function foo()
```

---

## 2. 외부 렉시컬 환경 참조

상위 스코프를 가리킨다.

즉 **스코프 체인을 구현하는 부분**이다.

예

```
inner → outer → global
```

---

# 6. 실행 컨텍스트 생성 과정

예제 코드

```javascript
var x = 1;

function foo() {
  var y = 2;
}

foo();
```

실행 과정

### 1. 전역 실행 컨텍스트 생성

전역 변수와 함수가 등록된다.

```
x
foo
```

---

### 2. foo 함수 호출

함수 실행 컨텍스트 생성

```
y
```

---

### 3. 함수 실행 종료

foo 실행 컨텍스트 제거

다시 전역 컨텍스트로 돌아간다.

---

# 7. 식별자 검색 과정 (스코프 체인)

자바스크립트는 식별자를 찾을 때 **현재 스코프 → 상위 스코프** 순서로 검색한다.

예

```javascript
var x = 1;

function foo() {
  var y = 2;

  console.log(x);
}

foo();
```

검색 과정

```
1. foo 내부 검색
2. 전역 스코프 검색
```

이 과정을 **스코프 체인**이라고 한다.

---

# 8. 실행 컨텍스트와 블록 레벨 스코프

ES6 이후 `let`과 `const`는 **블록 스코프**를 가진다.

```javascript
if (true) {
  let x = 10;
}

console.log(x); // ReferenceError
```

블록이 실행되면 **새로운 렉시컬 환경이 생성된다.**

즉 블록 단위로 스코프가 만들어진다.

---

# 정리

- 실행 컨텍스트는 자바스크립트 코드 실행 환경이다.
- 소스코드는 평가 단계와 실행 단계로 나누어 처리된다.
- 실행 컨텍스트는 스택 구조로 관리된다.
- 렉시컬 환경은 식별자와 스코프를 관리한다.
- 자바스크립트는 스코프 체인을 통해 식별자를 검색한다.
- let과 const는 블록 레벨 스코프를 만든다.

---

## 느낀 점

실행 컨텍스트는 자바스크립트의 동작 원리를 이해하는 핵심 개념이라 아주 중요하다..
특히 스코프 체인과 실행 컨텍스트 스택을 통해 코드가 어떤 순서로 실행되는지 이해할 수 있었고  
앞으로 클로저나 비동기 처리 개념을 이해하기 위해서도 확실한 정리가 필요한 파트임을 느꼈다.
